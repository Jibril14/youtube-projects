# Sticky Header for Elementor (Free) | CSS + JavaScript

Turn an existing Elementor header into a **sticky header** using only **CSS and vanilla JavaScript**—no Elementor Pro or premium add-ons required.

This project is designed for users who have **already built their header** and simply want to add sticky functionality.

🎥 **Watch the full tutorial here:** [Modern WordPress Header](https://youtu.be/5N0S01zHcqc?si=YakScHV2OscAj6kV)

## Features

- ✅ No Elementor Pro required
- ✅ Works with the free version of Elementor
- ✅ Compatible with Ultimate Addons for Elementor (UAE)
- ✅ Pure CSS and Vanilla JavaScript
- ✅ Smooth slide-down animation
- ✅ Responsive on Desktop, Tablet, and Mobile
- ✅ Lightweight and beginner-friendly

## Prerequisites

Before using this code, you should already have:

- A Top Bar (optional but recommended)
- A Main Header built with Elementor
- Ultimate Addons for Elementor (UAE)

## Setup

1. Assign an **ID** to your Top Bar:

```text
topbar-primary
```

2. Assign an **ID** to your Main Header:

```text
header-primary
```

3. Add the CSS to your website.

4. Add the JavaScript to your website.

That's it! Your existing header will automatically become sticky once the visitor scrolls past the top bar.

## Customization

Using different IDs?

Simply update these two lines in the JavaScript:

```javascript
const HEADER_ID = "header-primary";
const TOPBAR_ID = "topbar-primary";
```

Replace them with your own IDs.
