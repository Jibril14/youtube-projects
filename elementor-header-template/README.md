## Requirements

Before importing this template, make sure you have:

- WordPress installed
- Elementor (Free)
- Hello Elementor Theme (Recommended)

No Elementor Pro required.

## Installation

1. Download `elementor-header-template.json`
2. Login to your WordPress Dashboard.
3. Go to

```
Templates
→ Saved Templates
→ Import Templates
```
